# Quantisky

A beautiful weather analysis web application built with HTML, CSS, and JavaScript. Get comprehensive weather insights for any city, state, or country worldwide.

## Features

- **Global Coverage**: Search for any location worldwide
- **Today's Climate**: Large detailed display of current day's weather
- **Hourly Forecast**: Shows current hour and upcoming hours with temperature slider
- **7-Day Overview**: Past 3 days and future 3 days displayed in compact cards
- **Detailed Metrics**: Temperature, humidity/moisture, rainfall, wind speed
- **Live Date & Time**: Real-time clock display
- **Beautiful UI**: Animated background with rain drops and smoke effects
- **Responsive Design**: Works on desktop and mobile

## Tech Stack

- **HTML5, CSS3, JavaScript** (Vanilla)
- **APIs**: Open-Meteo Geocoding API & Forecast API (No API key required)

## How to Use

1. Open `index.html` in your web browser
2. Search for any city, state, or country
3. View comprehensive weather analysis
